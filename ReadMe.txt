※注意※
・全領域ステコンオバフロを持っているのでロードに時間がかかります。
・絶対パスのアドレス取得に際して落ちるときがあります。
（落ちる環境でも、何度かやってると落ちなくなる場合があります。）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このキャラクターはDisplayToClipboardステコンおよび、DBOF, CMDOF, 
FBOFの一切を使用せずに任意コード（AIファイルにあるコード）を実行
するテストキャラクターです。

実行するコードはメッセージボックスを表示するだけのコードです。
毎Ｆメッセージボックスを表示させるので、このキャラクターが何Ｆ
正常に行動できたのか、延いては対戦相手が何Ｆ行動させてくれるのか
を図る目安にもなると思います。

隔離耐性はないどころか、コード実行の都合上、勝手に死にます。
